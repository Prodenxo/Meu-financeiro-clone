## Story
**As a** contador/admin,  
**I want** que o DAS seja processado automaticamente no inicio de cada mes para os usuarios elegiveis,  
**so that** eu nao dependa de rotina manual cliente a cliente.

## Acceptance Criteria
1. Scheduler roda no dia 1 as 08:00 no timezone `America/Sao_Paulo`.
2. Job processa todos os usuarios da empresa do admin no escopo definido.
3. Documento base para processamento usa `cert_document` normalizado.
4. Para cada usuario/competencia, o sistema gera/baixa DAS, persiste PDF e grava status final.
5. Falhas individuais nao interrompem processamento do lote completo.
6. Execucao e idempotente por usuario/competencia.
