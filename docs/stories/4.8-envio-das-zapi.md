## Story
**As a** admin/contador,  
**I want** enviar a guia DAS MEI via WhatsApp usando Z-API,  
**so that** o cliente receba o PDF salvo em base64 no Supabase.

## Acceptance Criteria
1. O botão "Enviar por zap" usa o PDF base64 salvo em `DAS_mei` para envio via n8n.
2. Se não houver base64 salvo, o backend baixa a guia, persiste no `DAS_mei` e envia.
3. O n8n envia o PDF via Z-API `send-document/pdf` usando base64.
4. O fluxo atual do admin permanece funcionando (sem regressão de download).
5. Erros de telefone ausente ou falha no webhook são tratados com mensagem clara.

### Fluxo n8n (Z-API)
- Webhook recebe: `phone`, `message`, `competencia`, `fileName`, `pdfBase64`.
- HTTP Request para:
  - `POST https://api.z-api.io/instances/<instance>/token/<token>/send-document/pdf`
  - Header: `Client-Token: <client-token>`
  - Body JSON:
    ```json
    {
      "phone": "55DDDNumeros",
      "document": "data:application/pdf;base64,<pdfBase64>",
      "fileName": "das-mei-YYYYMM.pdf"
    }
    ```
