## Story
**As a** contador/admin,  
**I want** visualizar pendencias DAS em uma secao dedicada do painel administrativo,  
**so that** eu priorize rapidamente clientes pendentes por competencia.

## Acceptance Criteria
1. `AdminUserData` exibe secao "Pendencias DAS" com lista consolidada.
2. Secao possui estados de loading, vazio, erro e sucesso coerentes com a tela.
3. Usuario pode filtrar por competencia e buscar cliente.
4. Dados exibidos seguem o contrato da API admin DAS.
5. Demais blocos de `AdminUserData` permanecem sem regressao funcional.
