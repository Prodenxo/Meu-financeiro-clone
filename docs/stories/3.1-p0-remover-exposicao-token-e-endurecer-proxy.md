# Story 3.1: P0 - Remover exposicao de token e endurecer proxy sensivel

## Story
**As a** time de engenharia,  
**I want** eliminar exposicao de token de integracao ao cliente e proteger o proxy sensivel,  
**so that** o sistema reduza superficie de ataque sem quebrar fluxos essenciais.

## Acceptance Criteria
1. Nenhum endpoint retorna `access_token`/`jwt_token` de integracoes externas para o frontend.
2. Rotas de proxy de integracao sensivel exigem autenticacao explicita.
3. O proxy aplica validacao de superficie (metodos/caminhos permitidos) para reduzir abuso.
4. Fluxos existentes dependentes de integracao continuam funcionais apos ajuste.
5. Mudancas de contrato (quando houver) estao documentadas no backend e no frontend consumidor.
