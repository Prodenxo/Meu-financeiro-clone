## Story
**As a** admin da empresa,  
**I want** consultar pendencias DAS por competencia e cliente via API administrativa,  
**so that** o painel do contador tenha dados consolidados e confiaveis para triagem.

## Acceptance Criteria
1. Endpoint admin retorna lista consolidada de DAS com status `pago`/`pendente`/`erro`.
2. Endpoint suporta filtros por competencia, status e busca por cliente.
3. Escopo de resposta respeita isolamento por empresa do admin autenticado.
4. Endpoint de reprocessamento por usuario/competencia esta disponivel.
5. Contratos de payload sao estaveis para consumo frontend.
