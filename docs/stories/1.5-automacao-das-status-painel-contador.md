# Story 1.5: Automação mensal de DAS e pendências no painel do contador

## Status
Ready for Review

## Story
**As a** contador/admin da empresa,  
**I want** baixar automaticamente o DAS dos clientes a cada mês, visualizar se está pago ou pendente e enxergar pendências consolidadas no painel,  
**so that** eu acompanhe e cobre clientes inadimplentes com mais rapidez.

## Acceptance Criteria
1. O backend executa rotina mensal automática para gerar e armazenar PDF do DAS por cliente elegível.
2. O sistema persiste status de DAS por competência (`pago` ou `a_pagar`) e mantém histórico por usuário.
3. O painel do contador exibe lista consolidada de clientes pendentes de DAS por competência.
4. O escopo de visualização respeita empresa do admin autenticado.
5. O endpoint de pendências retorna dados necessários para o frontend sem expor segredos.
