## Story
**As a** superadmin,
**I want** editar empresas existentes e seus limites de MEI/nao-MEI,
**so that** eu ajuste a capacidade sem bloquear operacoes correntes.

## Acceptance Criteria
1. A API permite atualizar nome da empresa e limites (`max_mei`, `max_usuarios_nao_mei`) apenas para superadmins.
2. `listEmpresas` retorna os limites atuais para uso na UI.
3. A UI exibe lista/section de empresas para editar nome e limites (somente superadmin).
4. Ao salvar limites abaixo do uso atual, a API permite a edicao e apenas bloqueia novas criacoes/alteracoes que extrapolem o limite.
5. `0`/`null` continuam representando “sem limite”.
