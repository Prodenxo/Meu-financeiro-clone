## Story
**As a** time de qualidade e engenharia,  
**I want** cobrir fluxos criticos com testes automatizados minimos,  
**so that** regressões relevantes sejam detectadas antes de release.

## Acceptance Criteria
1. Existem testes automatizados minimos para fluxo de auth/session.
2. Existem testes automatizados minimos para emissao NFSe.
3. Existem testes automatizados minimos para processamento de webhook NFSe.
4. Existem testes automatizados minimos para download de PDF/XML da NFSe.
5. Evidencias de execucao dos testes ficam registradas para revisao de QA.
