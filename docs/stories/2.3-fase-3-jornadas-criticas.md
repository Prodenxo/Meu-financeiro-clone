## Story
**As a** usuario recorrente,  
**I want** jornadas criticas fluidas e sem friccao,  
**so that** eu conclua tarefas essenciais com rapidez e confianca.

## Acceptance Criteria
1. Fluxo de autenticacao (login, cadastro, esqueci/redefinir senha) e consistente e previsivel.
2. Fluxo de transacoes (criar, editar, excluir, filtrar, exportar) reduz friccao e melhora clareza.
3. Dashboard melhora leitura de informacao e interpretacao de estado financeiro.
4. Feedback de validacao e erro orienta o usuario para a proxima acao.
5. Nao ha regressao nas integracoes existentes (auth, categorias, orcamentos, agenda, mei/nfse).

## Tasks / Subtasks
- [ ] Task 1 (AC: 1): Consolidar jornada de autenticacao
  - [ ] Padronizar estrutura visual, microcopy e feedback em telas de auth
  - [ ] Validar fluxo de recuperacao e callback de autenticacao
- [ ] Task 2 (AC: 2): Melhorar jornada de transacoes
  - [ ] Refinar formularios/modais para reduzir erro de preenchimento
  - [ ] Padronizar feedback de acao (sucesso, falha, loading)
- [ ] Task 3 (AC: 3): Ajustar leitura de dashboard
  - [ ] Reforcar hierarquia visual e clareza de filtros/indicadores
  - [ ] Melhorar entendimento de status e totais
- [ ] Task 4 (AC: 4, 5): Validacao integrada
  - [ ] Executar regressao dos fluxos principais e integracoes
