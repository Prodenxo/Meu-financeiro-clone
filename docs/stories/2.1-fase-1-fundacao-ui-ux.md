## Story
**As a** usuario autenticado,  
**I want** uma base visual consistente em todas as telas,  
**so that** minha experiencia seja previsivel e facil de usar.

## Acceptance Criteria
1. O shell de layout autenticado e unificado (header/sidebar/main/bottom nav), sem duplicidade estrutural.
2. Componentes base (botao, input, card, alerta, badge) seguem padrao visual unico.
3. Uso de estilos inline e overrides pontuais e reduzido ao minimo necessario.
4. Estados de loading, sucesso e erro seguem padrao consistente.
5. Nao ha regressao funcional nas rotas autenticadas principais.

## Tasks / Subtasks
- [ ] Task 1 (AC: 1): Unificar shell de layout
  - [ ] Remover duplicidade de composicao de layout entre roteamento e paginas
  - [ ] Garantir comportamento consistente de scroll, espacamento e area util
- [ ] Task 2 (AC: 2, 3): Padronizar base visual
  - [ ] Consolidar classes utilitarias de componentes fundamentais
  - [ ] Reduzir estilos inline e regras ad hoc
- [ ] Task 3 (AC: 4): Padronizar feedbacks
  - [ ] Definir padrao de mensagens de erro/sucesso/carregamento
  - [ ] Aplicar padrao nas telas centrais
- [ ] Task 4 (AC: 5): Regressao rapida
  - [ ] Smoke test em dashboard, transacoes, categorias, orcamentos, agenda, settings e meu mei
