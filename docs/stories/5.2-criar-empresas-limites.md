## Story
**As a** superadmin,
**I want** criar empresas com limites de MEI e nao-MEI,
**so that** eu controle a capacidade por empresa antes de vincular usuarios.

## Acceptance Criteria
1. Superadmin consegue criar uma empresa via API informando `empresa`, `max_mei` e `max_usuarios_nao_mei` (inteiros >= 0; `null`/`0` = sem limite).
2. A tabela `empresas` possui as colunas `max_mei` e `max_usuarios_nao_mei` (migration aplicada).
3. Criacao/edicao de usuarios valida limites considerando apenas vinculos ativos (`status=true`), contando `mei=true` como MEI e `mei=false` como nao-MEI (quando `mei` for null, tratar como `true`).
4. Ao exceder limite, a API retorna erro 400 com mensagem clara indicando o limite atingido.
