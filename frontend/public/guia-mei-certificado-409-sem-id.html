Certificado já no Plugnotas — ID não obtido automaticamente

O aplicativo confirmou que o certificado existe na conta do emissor, mas não conseguiu obter o identificador (ID) pelas consultas automáticas. Confira CNPJ, conta em app2.plugnotas.com.br e se URL base + API key do servidor são do mesmo ambiente.

Checklist

  1. CNPJ do formulário com 14 dígitos, igual ao certificado e ao cadastro no Plugnotas.
  2. Mesma conta Plugnotas que a chave de API do backend.
  3. PLUGNOTAS_API_BASE_URL e PLUGNOTAS_API_KEY coerentes (sandbox/produção).
  4. Empresa existente na conta do provedor, se exigido para vincular certificado.
